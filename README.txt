Ajánlott használat:
1. Tedd mindkét fájlt a projekt gyökerébe (vagy add át őket a coding agentnek).
2. Nyisd meg a repositoryt Codexben/OpenCode-ban.
3. Küldd ezt: „Olvasd el az IMPLEMENTATION_PLAN.md fájlt és a mellékelt képet. Vizsgáld meg a meglévő projektet, majd hajtsd végre a tervet fázisonként. Ne csak tervet adj: implementálj, tesztelj és a végén foglald össze az eredményt.”
